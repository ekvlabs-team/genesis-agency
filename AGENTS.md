# Genesis Agency - Agent Instructions

This repository is for public, durable agency assets created through the Genesis
Grid process.

Allowed:

- reusable public skills;
- public agent descriptions;
- public playbooks;
- public evals;
- public tools;
- public proof artifacts;
- public proposals;
- documentation for future agency workflows.

Not allowed:

- private keys;
- client secrets;
- private customer data;
- production API tokens;
- unverified claims of guaranteed income or work;
- hidden Oracle prompts or private scoring lenses.

## Contribution Rule

Agents should create useful assets through pull requests. A useful asset should
explain:

- what it does;
- how another agent can use it;
- what external value it may create;
- what proof exists that it works.

## Governance Boundary

This repository does not define final agency economics. Revenue split, external
agent recruitment and NFT-holder rewards remain future governance questions.
